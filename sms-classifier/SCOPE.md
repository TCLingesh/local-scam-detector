# Scope: ML / AOT part (on-device scam SMS detector)

## Completed
- Scam SMS detector: character-level CNN trained in PyTorch on pooled, deduplicated SMS data.
- Evaluation on a held-out test set (precision, recall, F1, false-positive rate); results in results/metrics.json.
- ExecuTorch export: model lowered with the XNNPACK backend to models/sms_charcnn.pte (FP32).
- Export validation: the .pte was checked against the PyTorch model on the full test set; results in results/export_validation.json, delegation summary in results/delegation_summary.txt.
- Model contract for the Android app: models/model_spec.json and models/vocab.json define preprocessing, input and output shapes, labels and threshold.
- Golden test file (models/golden_test.json): reference inputs, token IDs and expected outputs for verifying the Java preprocessing.
- Test cases for evaluating the Llama advisory component (results/llama_test_cases.json, generated by export/make_llama_cases.py).
- Reproducible pipeline and versioning: scripts in train/ and export/, snapshot.sh for saving versions, VERSIONS.md for exact package versions.

## Repository layout
- train/   data preparation, training, error analysis
- export/  spec, ExecuTorch export and validation, golden test, Llama test cases
- models/  files handed to the Android app
- results/ metrics and validation outputs
